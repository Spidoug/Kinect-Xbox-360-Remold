# Security policy

## Supported release

Security fixes are currently targeted at the V1 release line.

| Version | Supported |
| --- | --- |
| 1.0.x | yes |
| older/unreleased layouts | no |

## Reporting

Do not publish credentials, private signing keys, package-signing secrets or sensitive host/network configuration in a public issue.

For IP-camera issues, include configuration structure and logs only after removing passwords, tokens and private addresses that are not necessary to reproduce the problem.

The repository must never contain the maintainer's private code-signing key. Public development certificates may be distributed when intentionally generated by the documented Windows build flow.
